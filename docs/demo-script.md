# T3N Demo Script (about 90 seconds)

## 0:00–0:15 — Problem

Paid tasks are fragmented and risky to automate blindly. Independent professionals need help finding and checking work without exposing credentials, paying fees, or accepting unclear terms.

## 0:15–0:30 — Solution

T3N is a guarded professional agent built with the Strands Agents SDK. It evaluates each opportunity and starts work only when AI use, reward, Bulgarian eligibility, zero cost, legal clarity, and payout safety are verified.

## 0:30–0:50 — Architecture

Marketplace adapters feed typed opportunities to the Strands agent. Deterministic policy sits below the model, so model reasoning cannot bypass the safety gates. Every result is written to a hash-chained audit log.

## 0:50–1:10 — Working demo

The safe SEPA task passes every gate and reaches CLAIMED under the user's standing policy. A second task with an unconfirmed reward, crypto payout, and KYC requirement stops at REVIEW REQUIRED before any action.

## 1:10–1:25 — Impact

T3N gives solo professionals greater reach while preserving human authority. It automates repetitive verification, stays honest about uncertainty, and fails closed whenever the evidence is incomplete.
